# APE04_Individual

A lo largo de esta práctica se construyó un sistema de control de estudiantes y calificaciones aplicando programación orientada a objetos en C++ y Java. El proyecto gira en torno a una clase llamada Estudiante, diseñada con atributos privados como cédula, nombre, apellido y tres notas, accesibles únicamente mediante getters y setters. La clase cuenta con un constructor que inicializa todos los datos, un método calcularPromedio() que obtiene la media aritmética de las notas, y un método determinarEstado() que decide automáticamente si el estudiante aprueba o reprueba según la condición de promedio mayor o igual a 7.00. 

El programa registra un mínimo de cinco estudiantes, valida que cada nota ingresada esté dentro del rango permitido de 0 a 10, y al finalizar muestra un resumen con el total de aprobados y reprobados. La misma lógica fue implementada en ambos lenguajes, lo que permitió comprobar que los conceptos de encapsulación y diseño de clases son universales e independientes de la sintaxis. 

Todo el código fue organizado en un repositorio GitHub con commits estructurados, siguiendo buenas prácticas de control de versiones propias del desarrollo profesional de software.
